## 4. 說明製作流程和相關操作
開啟 Unity 6.6 版本，建立專案。 在 Scene 視窗中選取 3D 人形模型 (FinalBaseMesh)。
接下來使用移動 (W) 與旋轉 (E) 工具調整物件的位置與面向。
最後調整 Main Camera 視角，將攝影機畫面完全對準人物。
